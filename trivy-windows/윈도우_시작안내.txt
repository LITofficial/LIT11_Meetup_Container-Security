윈도우용 Trivy 검사 사이트

1. Docker Desktop for Windows 설치 후 실행하고 초기 설정을 완료하세요.
   https://www.docker.com/products/docker-desktop/
   WSL 2 설치/업데이트 또는 재부팅 안내가 나오면 Docker 공식 안내에 따라 완료하세요.
   Docker Desktop은 Linux containers 모드로 사용합니다.
2. ZIP을 우클릭 → 모두 압축 풀기. ZIP 안에서 직접 실행하지 마세요.
3. 사이트시작.bat를 더블클릭하세요. 보통 관리자 권한은 필요하지 않습니다.
4. 준비가 끝나면 브라우저가 http://localhost:8080 으로 열립니다.
5. 파일 선택 → samples 폴더의 .tar → 검사하기.
6. 종료는 사이트종료.bat 더블클릭.

사이트시작.bat는 Trivy와 사이트를 빌드하고, 취약점 DB 및 Java 분석 DB를 사전에 내려받습니다.
DB가 ZIP에 포함된 것은 아닙니다. 최초 실행은 인터넷과 다운로드 시간이 필요합니다.
이후 실행은 캐시된 DB를 갱신하며 검사 중 DB 재다운로드는 건너뜁니다.
완전 오프라인 동작은 검증하지 않았으므로 발표 시 인터넷 연결을 유지하세요.

보안 경고가 나오면 파일의 출처와 내용을 확인하세요. 조직에서 차단한 경우 보안 정책을 우회하지 말고 담당자에게 문의하세요.
실행 실패 시 창에 표시된 오류를 캡처해주세요.

현재 사이트는 이 PC에서만 접속합니다. 관객용 공개 주소는 생성되지 않습니다.
실제 컨테이너 이미지 .tar 대상이며 JPG/PNG는 지원하지 않습니다.
파일은 docker save로 저장한 형식이어야 하며 최대 80MB입니다.
예제 .tar는 압축을 풀지 말고 그대로 업로드하세요.
예제는 검사 전용 Log4j 이미지로 실행할 웹 서비스가 아니며 두 버전 모두 최신 DB에서 FAIL일 수 있습니다.
PASS는 완벽한 안전이나 실제 배포 허가를 보장하지 않습니다.

검증 범위: 패키지 구성, Python/JavaScript 문법, 배치 파일의 분기/명령 순서를 검토했습니다.
제작 환경에서 Windows, Docker 또는 Trivy를 실제 실행하지 못했습니다.
서버 단위 테스트도 Flask 의존성이 없어 실행하지 못했습니다.
추가 제한은 README.md를 확인하세요.
