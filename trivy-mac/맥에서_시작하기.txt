맥에서 실행하는 Trivy 검사 사이트

1. Docker Desktop을 설치하고 실행합니다. 최초 설정을 완료해주세요.
   https://www.docker.com/products/docker-desktop/
2. 이 압축파일을 풀고 사이트시작.command를 더블클릭합니다.
3. 사이트와 취약점 DB를 준비한 뒤 브라우저가 자동으로 열립니다.
4. 파일 선택 → samples 폴더의 .tar 선택 → 검사하기.
   tar 파일은 압축을 풀지 마세요.

처음에는 다운로드 때문에 오래 걸릴 수 있습니다. 이후 DB 캐시를 재사용합니다.
시작 때 DB를 갱신하고 검사 때는 해당 DB를 그대로 사용합니다.
Java용 DB도 사전에 다운로드합니다. 완전 오프라인 동작까지 검증된 것은 아니므로 발표 시 인터넷 연결을 유지하는 것을 권장합니다.

맥에서 차단하면:
파일을 Control-클릭 → 열기를 시도하세요. 신뢰하는 파일에 한해서만 실행하세요.
실행 권한 오류가 있으면 터미널에 bash와 공백을 입력하고 사이트시작.command를 끌어넣은 뒤 Enter를 누르세요.

종료: 사이트종료.command 더블클릭.
이 사이트는 내 맥의 http://localhost:8080 에서 사용합니다. 다른 사람에게 공개된 링크가 아닙니다.

화면: 컨테이너 .tar 업로드 → 실제 Trivy 검사 → CRITICAL이면 배포 불가 판정.
PASS는 완벽한 안전을 뜻하지 않습니다. 실제 배포를 실행하거나 차단하지 않습니다.
예제는 Log4j 2.14.1과 2.24.3이며 두 파일 모두 최신 DB에서 FAIL일 수 있습니다.
예제는 검사 전용 이미지이며 실행할 웹 서비스는 포함하지 않습니다.

확인 범위: 코드 문법과 파일 구조 확인. 실제 macOS/Docker/Trivy 구동은 제작 환경에서 실행 검증하지 못했습니다.
서버 단위 테스트도 Flask 의존성이 없어 실행하지 못했습니다.
기존 README.md의 세부 제한도 함께 확인하세요.
